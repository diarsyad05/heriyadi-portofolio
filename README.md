# Portofolio Heriyadil Arsyad
Website profil ringkas dan elegan, responsif di HP, dengan foto resolusi tinggi. Berisi profil, pendidikan, serta minat pengembangan diri.

## Pratinjau
Buka index.html langsung di browser.

## Publikasi di Vercel
1. Ekstrak ZIP ini.
2. Unggah seluruh isi folder ke repositori GitHub, dengan index.html di root repositori.
3. Di Vercel pilih Add New → Project, lalu impor repositori.
4. Framework Preset: Other; tanpa Build Command dan Install Command; Output Directory: `.`.
5. Klik Deploy untuk mendapatkan alamat .vercel.app.

## Edit
- Identitas dan narasi: index.html.
- Tampilan: style.css.
- Foto: assets/heriyadil-arsyad-hd.webp.

Situs profil pribadi. Konten berdasarkan informasi yang diberikan, tanpa penambahan riwayat jabatan maupun prestasi yang belum dikonfirmasi.
